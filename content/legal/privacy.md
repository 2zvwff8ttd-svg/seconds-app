# プライバシーポリシー

最終更新日：2026年7月18日

?Seconds（以下「本サービス」といいます）は、本サービスを運営する?Seconds 運営（以下「運営者」といいます）が、利用者の個人情報その他の情報を適切に保護することを重要な責務と考え、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

## 1. 取得する情報

本サービスは、提供にあたり以下の情報を取得・利用します。これらは、App Store の「App Privacy（アプリのプライバシー）」における申告内容とも対応しています。

### 1.1 アカウント情報
- メールアドレス（認証・ログイン・パスワード再設定のため）
- パスワード（認証基盤により適切に管理されます）
- ユーザー名、表示名、自己紹介、プロフィール画像

### 1.2 投稿コンテンツおよびユーザーコンテンツ
- 写真・動画（利用者が撮影・投稿した動画、サムネイル、保存用に生成した動画など）
- オーディオデータ（投稿動画に含まれる音声。利用者が録音・合成した音声を含む場合があります）
- その他のユーザーコンテンツ（タイトル、コメント、プロフィール文など）
- メッセージ（DM の本文）

### 1.3 識別子
- ユーザーID（アカウントを識別するための識別子）
- デバイスIDに相当する情報として、iOS 向けプッシュ通知用の APNs（Apple Push Notification service）デバイストークン

### 1.4 おおよその位置情報（国コード）
- 国レベルの地域情報（国コード）を取得します。詳細な位置情報（GPS 等）は取得しません。
- 国コードは、主に端末の言語・地域設定から判定します。地域情報が得られない場合に限り、IPアドレスから国を推定する外部サービス（ipapi.co）へ問い合わせることがあります。判定できない場合は既定値（日本）を用いることがあります。
- 国コードは、国別の王冠（デイリーバイラル）判定やフィード表示などに使用します。

### 1.5 製品の操作（利用状況）
- 視聴に関する情報（視聴の進行度、視聴完了の有無、視聴回数など）
- いいね、フォロー関係
- レコメンド（おすすめ表示）のための利用シグナル

### 1.6 その他、サービス提供上必要な技術情報
- ログイン状態の維持などに必要な Cookie 等
- ホスティング・認証・通知の過程で、通信上必要な情報が各事業者側で処理される場合があります（例：IPアドレス）。運営者がアプリ内で精密な端末識別子（広告ID 等）を収集することはありません。

## 2. 利用目的

取得した情報は、以下の目的で利用します。

- 本サービスの提供、維持、改善のため
- 利用者の認証およびアカウント管理のため
- 投稿コンテンツの公開・配信、保存・共有機能の提供のため
- メッセージ（DM）の送受信のため
- おすすめコンテンツの表示（レコメンド）のため
- 国別ランキング（王冠）など国コードを用いる機能のため
- プッシュ通知・アプリ内通知の送信のため
- AI 機能（タイトル提案、プロフィール画像の加工など）の提供のため
- 不正利用の防止、安全性の確保、通報・モデレーション対応のため
- 利用者からのお問い合わせ対応のため
- 法令に基づく対応のため

## 3. 第三者提供

運営者は、以下の場合を除き、取得した個人情報を第三者に提供しません。

- 利用者の同意がある場合
- 法令に基づく場合
- 人の生命、身体または財産の保護のために必要であり、本人の同意を得ることが困難な場合

なお、本ポリシー第4条に記載する外部サービスへの委託（処理の委託）は、ここにいう第三者提供とは別に行われます。運営者は、広告目的での第三者への販売や、広告トラッキングを目的とした識別子の利用は行いません。

## 4. 業務委託（外部サービスの利用）

本サービスは、運営にあたり以下の外部サービスを利用しており、これらのサービスのサーバーで情報が処理・保管される場合があります。事業者によっては日本国外にサーバーを有し、情報が国外に移転される可能性があります。各事業者のプライバシーポリシーもあわせてご確認ください。

| サービス | 利用目的の概要 |
| --- | --- |
| Supabase | 認証、データベース、ファイルストレージ、サーバー処理の提供 |
| Vercel | 本サービスの Web アプリケーションのホスティング、API の実行 |
| Google（Gemini） | 投稿時の AI によるタイトル・シーン提案等のため、投稿動画の先頭フレーム画像等を処理 |
| OpenAI | 利用者が選択した場合に、プロフィール画像を加工（証明写真風など）するために画像を処理 |
| ipapi.co | 端末の地域設定から国コードが得られない場合の、IPアドレスに基づく国コード推定 |
| Apple（APNs） | iOS 端末へのプッシュ通知の配信（デバイストークンの利用を含む） |

補足：
- AI による BGM 生成など、将来または試験的に他の外部 API を利用する場合は、利用開始時に本ポリシーを更新します。
- 本サービスは、広告 SDK や第三者広告トラッキング SDK を利用していません。

## 5. プッシュ通知について

本サービスは、iOS において Apple Push Notification service（APNs）を利用してプッシュ通知を送信することがあります。その際、端末を識別するためのデバイストークンを取得・保存し、通知の配信に使用します。利用者は端末の設定、または本サービス内の通知設定から、通知の受け取りを管理できます。ログアウト時などには、トークンの利用を無効化する処理を行います。

## 6. データの保持期間

### 6.1 投稿動画
- 公開された投稿は、公開から約10日後に自動削除されます。削除対象には、関連する動画ファイル、クリップ、サムネイル等のメディアが含まれます。
- 利用者は、公開期間内であっても、本サービス内の削除機能により自己の投稿を削除できます。
- 自動削除は定期処理により実施されるため、正確な削除時刻は公開から約10日経過後の処理実行タイミングにより前後する場合があります。

### 6.2 アカウントに紐づくその他のデータ
- プロフィール、コメント、いいね、フォロー、DM、視聴・利用シグナル、プッシュ通知用トークン等は、アカウントが存続する間、サービス提供に必要な範囲で保持します。
- 端末内に一時保存される下書きデータは、端末上で一定期間（およそ48時間）の後に失効するよう設計されています。

### 6.3 アカウント削除時の扱い
利用者は、本サービスの設定画面からアカウント削除を申し込むことができます。アカウント削除が完了すると、運営者は原則として以下を削除します。

- プロフィール情報およびプロフィール画像
- 投稿動画および関連メディア
- コメント、いいね、フォロー関係
- メッセージ（DM）
- 視聴・利用に関する記録
- プッシュ通知用のデバイストークン
- 当該利用者に関連する通報記録（実装上削除されるものを含む）

法令に基づき保存が義務付けられる情報がある場合は、その範囲で保持することがあります。削除処理の完了まで、システム上の都合により時間がかかることがあります。

## 7. 個人情報の開示・訂正・削除

利用者は、運営者に対して自己の個人情報の開示、訂正、利用停止、削除を請求することができます。

- アカウント削除は、本サービス内の設定から行うことができます。
- その他の請求は、下記のお問い合わせ窓口までご連絡ください。本人確認のうえ、法令に従い遅滞なく対応します。

## 8. Cookie等の利用

本サービスは、利便性向上やログイン状態の維持のため Cookie 等の技術を使用する場合があります。利用者はブラウザの設定により Cookie を無効化できますが、その場合本サービスの一部機能が利用できなくなることがあります。

## 9. 海外からの利用について

本サービスは日本国内からの利用を主に想定していますが、海外からも利用される可能性があります。海外の利用者については、お住まいの国・地域の法令により追加の権利が認められる場合があります。

## 10. 安全管理

運営者は、取得した情報の漏えい、滅失またはき損の防止その他の安全管理のために必要かつ適切な措置を講じます。

## 11. 年齢制限

本サービスは13歳以上の方を対象としています。13歳未満の方は本サービスを利用できません。

## 12. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本サービス上で告知します。変更後の本ポリシーは、本サービス上に掲載した時点から効力を生じるものとします。
